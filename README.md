# eng-remember

Telegram-бот для запоминания английских слов с интервальным повторением (FSRS).

> Статус: каркас проекта. Сквозной сценарий работает от начала до конца;
> продуктовые фичи добавляются поверх готовых слоёв.

## Что умеет сейчас

- **Добавление слов свободным текстом.** Пишете `ubiquitous — вездесущий` или
  `добавь слова resilient и thorough` — бот разбирает сообщение, показывает
  карточки на подтверждение и сохраняет только по нажатию.
- **Подбор слов по теме или из текста.** `ещё 10 слов про медицину` — модель
  подберёт лексику. Пришлёте абзац текста — найдёт слова в нём, причём каждое
  проверяется: слово, которого в тексте нет, до вас не дойдёт. Кнопка
  «🔄 Ещё слова» даёт другую подборку, не сохраняя текущую.
- **Слово с контекстом и слова того же домена — одним сообщением.**
  `arrangement как во фразе The graded evaluation criteria is an arrangement of
  descriptions … и ещё пару слов на эту тему` — слово станет карточкой с
  переводом по смыслу из фразы, а рядом встанут подобранные слова того же
  домена; всё это один пакет с одной кнопкой «Сохранить». «🔄 Ещё слова»
  меняет только найденную половину — ваше слово остаётся в пакете.
- **Уточняющие вопросы.** Если запрос слишком расплывчатый (`хочу ещё слов` без
  темы и контекста), бот задаст один вопрос с вариантами ответа — или предложит
  решить самому. Если у слова запрошены «слова того же домена», а домен не
  читается ни из слова, ни из контекста, бот спросит тему вместо того, чтобы
  подбирать слова по случайному смыслу. Больше двух уточнений подряд он не
  задаёт.
- **Повторение по FSRS с вводом ответа.** `/review` показывает слово, а вы пишете
  перевод — или жмёте «🤷 Не знаю». Бот сам сверяет ответ: совпадение сразу,
  несовпадение — через модель, если она подключена. Оценку бот ставит сам: верно
  и быстрее 5 секунд — «Легко», верно, но дольше — «Нормально», почти —
  «Трудно», неверно или «Не знаю» — «Не помню». Правильное значение показывается
  после вашего ответа, поэтому вспоминать приходится самому. В день добавления
  новое слово на повторение не выпадает: первое повторение наступает со
  следующего дня.
- **Контекст и лечение.** На повторе кнопка «💡 Подсказка» показывает пример с
  пропущенным словом — после подсказки лучший рейтинг «Нормально». Примеры не
  повторяются: каждое повторение показывает следующее предложение, а старым
  карточкам примеры догенерируются в фоне, если подключена модель. Слово,
  проваленное четыре раза кряду, получает меню: мнемоника, свежий пример,
  пауза (`/paused`), оставить.
- **Тренировка вне расписания.** «🏋️ Тренировка» или `/practice` — квиз из
  четырёх вариантов по случайным уже знакомым словам. Интервалы, серия и
  статистика не затрагиваются; на экране «повторять нечего» бот сам предлагает
  потренироваться.
- **Экспорт и импорт.** `/export` отдаёт все слова файлом CSV (разделитель `;`,
  UTF-8, колода и теги внутри). `/import` — или просто присланный CSV-файл —
  показывает предпросмотр и сохраняет только по подтверждению: дубли
  пропускаются, незнакомые колоды создаются, строки без перевода пропускаются,
  а с подключённой моделью переводы дозаполняются.
- **Серии и заморозки.** День засчитывается с первого ответа, серия растёт, за
  каждые 7 дней подряд даётся заморозка. Пропущенный день заморозка закрывает
  сама и сообщает об этом; без заморозки серия прерывается. Всё видно в `/stats`.
- **Похвала после ответа.** 140 шаблонов, разложенных по четырём банкам
  (нормально / легко / трудно / не помню) плюс отдельный банк для круглых дат.
  Выбор идёт «мешком»: каждый шаблон используется один раз, прежде чем какой-то
  повторится, а закрывший цикл шаблон исключается из начала следующего.
- **Напоминания.** Утром — если есть что повторять, с состоянием серии.
  Вечером — предупреждение, что серия под угрозой, но только пока её ещё можно
  спасти. Время в своём часовом поясе, настраивается через `/remind`.
- **Статистика и настройки.** `/stats`, `/decks`, `/paused`, `/limit`, `/tz`,
  `/remind`.
- **Работа без LLM.** Без ключа бот понимает пары «слово — перевод»; подбор слов
  и уточнения требуют модели и честно об этом сообщают, а ответ на карточке
  проверяется только точным совпадением.

## Быстрый старт

Нужны Python 3.12+, [uv](https://docs.astral.sh/uv/) и Docker.

```bash
cp .env.example .env          # вписать BOT_TOKEN от @BotFather
make install
make db-up                    # Postgres в Docker на порту 55432
make migrate                  # применить миграции
make run                      # запустить бота
```

Ключ LLM не обязателен: без него включается разбор по правилам. Чтобы подключить
модель, заполните `LLM__API_KEY` и при необходимости `LLM__BASE_URL` —
подойдёт любой OpenAI-совместимый эндпоинт (OpenAI, OpenRouter, DeepSeek, vLLM,
Ollama). Расход на модель ограничен на пользователя: `LLM__MAX_CALLS_PER_HOUR`
и `LLM__MAX_TOKENS_PER_DAY` (0 — без ограничения), при исчерпании бот отказывает
до вызова, а не после.

Напоминания рассылает сам бот — отдельный планировщик не нужен. Если бот
масштабируется на несколько реплик, включите `REMINDERS__ENABLED=false` и
запускайте `eng-remember-remind` из cron: иначе каждая реплика отправит своё.

## Деплой

```bash
cp .env.example .env          # BOT_TOKEN и, при необходимости, LLM__*
docker compose --profile full up -d --build
docker compose logs -f bot
```

Схему создаёт одноразовый сервис `migrate`, который проходит до старта бота,
поэтому на пустом сервере всё поднимается одной командой, а обновление сводится
к `git pull` и повторному `up -d --build`.

Креды к LLM, бэкап, диагностика и деплой в несколько реплик —
[docs/deploy.md](docs/deploy.md).

## Как это устроено

Текст → парсер (LLM или правила) → подтверждение → карточки в Postgres →
очередь повторений → оценка → FSRS пересчитывает интервал.

```
src/eng_remember/
├── domain/        правила: FSRS, серии, банк похвал — без БД и Telegram
├── db/            движок, сессия, тип UtcDateTime
├── models/        таблицы SQLAlchemy
├── repositories/  все SQL-запросы
├── services/      сценарии: карточки, повторение, серии, подбор слов, LLM
└── bot/           роутеры, middleware, клавиатуры, тексты
```

Правила серий и выбор похвалы — чистые функции над неизменяемым состоянием,
поэтому и «заморозка закрыла пропуск», и «шаблон не повторится, пока не кончится
банк» проверяются обычным тестом с явной датой, без базы и бота.

Полное описание решений, модели данных и компромиссов —
[docs/superpowers/specs/2026-10-12-eng-remember-design.md](docs/superpowers/specs/2026-10-12-eng-remember-design.md).

## Проверки

```bash
make lint        # ruff
make typecheck   # mypy --strict
make test        # 379 юнит-тестов, без инфраструктуры
make test-all    # + 14 интеграционных против Postgres
make audit       # pip-audit по зафиксированным зависимостям (нужна сеть)
```

Тесты гоняют бота через настоящий диспетчер с подменённой только отправкой в
Telegram, так что проверяют маршрутизацию, фильтры и разбор callback-данных, а не
их имитацию. Регрессии на экранирование и prompt injection собраны в
`tests/test_security.py`.

Инциденты, логи и лимиты — в [docs/security.md](docs/security.md). Установка на
сервер, креды к модели, бэкап — в [docs/deploy.md](docs/deploy.md).
