# Очередь доработок eng-remember по ревью 26 ноября 2026

Задачи основаны на ревью `origin/main` (`50a8b20`). Порядок учитывает риск для данных, затем влияние на повторение и точность сообщений бота. Статус отмечается после прохождения критериев приёмки.

## 1. P2 — исключить содержимое ответов из аудита LLM при выключенном логировании

Строка ошибки валидации включает исходное значение поля. При `LOG_LLM_PAYLOADS=false` оно остаётся в `llm_calls.error` даже после очистки `request_text` и `response_text`. Использовать безопасное описание ошибки с типом и путём к полю для аудита и журналов приложения. [Клиент LLM](../../../src/eng_remember/services/llm/client.py#L491), [запись аудита](../../../src/eng_remember/services/llm/factory.py#L56), [тесты клиента](../../../tests/test_llm_client.py).

- [x] При выключенном флаге синтетическое значение из невалидного ответа отсутствует во всех текстовых полях записи аудита и в журналах приложения.
- [x] Аудит сохраняет пригодную для диагностики категорию ошибки, модель и номер попытки. Повтор запроса для исправления структуры ответа и переключение на резервный маршрут работают.

## 2. P2 — привязать кнопки к конкретному предпросмотру импорта

Подтверждение из первого предпросмотра сохраняет данные второго, поскольку обработчик проверяет лишь тип состояния FSM. Привязать действия к идентификатору предпросмотра и проверять его перед чтением или изменением текущего набора. [Импорт CSV](../../../src/eng_remember/bot/routers/files.py#L159), [добавление из текста](../../../src/eng_remember/bot/routers/capture.py#L588), [тесты CSV](../../../tests/test_bot_files.py), [тесты добавления](../../../tests/test_bot_flow.py).

- [x] После предпросмотров A и B кнопки сохранения и отмены из A показывают сообщение об устаревшей кнопке. B остаётся доступен для подтверждения и сохраняет только свой набор.
- [x] Проверка покрывает CSV и обычный текст. Старая кнопка «Ещё слова» не меняет новый предпросмотр и не запускает запрос к модели.
- [x] Повторное нажатие подтверждения сохраняет набор один раз.

## 3. P2 — сделать выгруженные CSV пригодными для обратного импорта

Экспорт записывает до 5 000 слов в один CSV, импорт обрабатывает до 1 000 строк данных и принимает файл размером до 1 000 000 байт. Разбивать выгрузку на файлы по обоим ограничениям с учётом заголовка и UTF-8 BOM. [Роутер экспорта](../../../src/eng_remember/bot/routers/files.py#L66), [CSV-формат и лимиты](../../../src/eng_remember/services/csv_io.py#L30), [тесты CSV](../../../tests/test_csv_io.py).

- [x] Выгрузка на 1 000 коротких строк даёт один файл. Выгрузка на 1 001 строку даёт два файла, которые можно последовательно импортировать без потери строк из-за лимитов.
- [x] Длинные строки с многобайтными символами разделяются по размеру. Каждый файл укладывается в лимит после кодирования и имеет свой заголовок.
- [x] В тесте полного цикла сохраняются слово, перевод, язык, теги и колода. Если выгрузка ограничена общим числом строк, подпись сообщает, сколько слов выгружено из коллекции.

## 4. P2 — учитывать обратные карточки при планировании напоминаний

После первого повторения прямой карточки на следующий день может быть доступна только новая обратная карточка. `/review` её предлагает, а подсчёт очереди для напоминаний исключает её по направлению. Применить в подсчёте те же правила доступности, что и при подборе карточек для повторения. [Подсчёт в репозитории](../../../src/eng_remember/repositories/cards.py#L302), [подбор очереди](../../../src/eng_remember/services/review.py#L125), [тесты напоминаний](../../../tests/test_services_reminders.py).

- [x] Утреннее напоминание приходит, когда доступна одна новая обратная карточка и `/review` выдаёт её.
- [x] Подсчёт учитывает дневной лимит, исключает вторую сторону слова после повторения первой в тот же локальный день и считает пару новых сторон один раз.
- [x] Выбор кандидатов остаётся пакетным. Условия утреннего и вечернего напоминания проверены на существующих сценариях.

## 5. P3 — показывать модель, которая разобрала сообщение

После успешного переключения аудит указывает резервную модель, а предпросмотр берёт статическое имя основной. Передавать информацию о модели с результатом конкретного вызова. [Маршрутизация LLM](../../../src/eng_remember/services/llm/client.py#L625), [результат разбора](../../../src/eng_remember/services/llm/parser.py#L94), [тесты переключения](../../../tests/test_llm_failover.py).

- [x] Когда основная модель недоступна, предпросмотр и успешная запись аудита называют резервную модель.
- [x] При успехе основной модели предпросмотр называет её. При разборе правилами показывается существующий текст для этого режима.
- [x] Одновременные запросы получают имя модели своего ответа.
